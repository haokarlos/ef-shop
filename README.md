# Eros Fantasy Shop

Esta es la tienda web para el juego Eros Fantasy.

## Archivos

- `index.html`: página principal.
- `logo.jpg`: logo del juego (subir imagen tuya aquí).
- `banner.jpg`: banner de la tienda (subir imagen tuya aquí).

## Cómo usar

1. Añade las imágenes `logo.jpg` y `banner.jpg` a la carpeta raíz del repositorio.
2. Haz commit y push para subirlas a GitHub.
3. La tienda estará visible en la URL que Vercel proporciona al conectar este repositorio.
